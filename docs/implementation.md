# Обзор реализации AivibeBoard

Документ описывает фронтенд-скелет **AivibeBoard** — SaaS-интерфейс управления проектами в духе Trello / Jira / Linear / Notion с акцентом на AI-блоки. Реализован **только клиент**: без бэкенда, базы данных, внешней авторизации и настоящих AI-запросов.

---

## Цель и границы

- **Сделано:** полноценный каркас приложения, рабочий дашборд, заглушки остальных разделов с реальными UI-взаимодействиями на мок-данных.
- **Не сделано:** API, персистентность после перезагрузки страницы (кроме того, что уже в Zustand до refresh), Telegram, почта, настоящие модели AI.

Данные живут в памяти сессии браузера. Кнопки и формы, которые выглядят рабочими, выполняют действие в рамках демо.

## Структура кода

```
src/
  app/           App, router
  components/    layout (Sidebar, Header, Search), ui-kit
  data/          mockUsers, mockTasks, mockProjects, …
  features/      dashboard, tasks, projects, ai-assistant, …
  hooks/         useWorkspaceData, useMediaQuery, useOnOutside
  pages/         страницы по маршрутам
  store/         useAppStore (Zustand)
  types/         доменные типы и константы статусов
  utils/         format, ai (шаблоны), tones, guards
```

Импорты локальных модулей — с расширением `.ts` / `.tsx` (требование `verbatimModuleSyntax`).

## UI и layout

- Оболочка: `h-svh`, боковая панель ~250px, на экранах `< lg` — выезжающее меню и оверлей.
- Визуальный стиль: светлый SaaS, zinc/white, акцент indigo/violet, AI-блоки на violet-фоне.
- **Header:** хлебные крошки, поиск по проектам/задачам, «Новая задача», уведомления, аватар.
- **Sidebar:** переключатель workspace (Aivibe / Студия Northwind), навигация, профиль.

---

## Состояние (Zustand)

Store `useAppStore` хранит:

- задачи, проекты, активность, документы, историю AI;
- текущего пользователя (`alex` — Алексей Морозов);
- активный workspace;
- флаги: sidebar, модалка создания задачи, Telegram по workspace;
- настройки: компактные списки, дайджест, алерты (переключатели без реальной отправки).

Мутации добавляют записи в ленту активности с русскими сообщениями в кавычках «ёлочками».

## Доменные значения (русский UI)

Статусы задач: **К выполнению**, **В работе**, **На проверке**, **Готово**.

Приоритеты: **Низкий**, **Средний**, **Высокий**, **Критический**.

Статусы проектов: **По плану**, **Под угрозой**, **На паузе**, **Завершён**.

Категории документов: **Продукт**, **Разработка**, **Дизайн**, **Операции**.

Даты в интерфейсе — `ru-RU`; относительное время: «Только что», «N мин. назад», «N ч. назад», «N дн. назад». Для счётчиков используется `plural()` (задача / задачи / задач).

## Ключевые взаимодействия

1. **Создание задачи** — модалка, добавление в store, запись в активность.
2. **Смена статуса** — select в списке задач; при «Готово» — тип события `completed`.
3. **Поиск** — проекты и задачи текущего workspace, Enter переходит к первому результату.
4. **AI** — `src/utils/ai.ts`: regex по русским и английским ключевым словам (маркетинг, сайт, бот, дизайн, данные…), до 5 подзадач; история до 12 записей на workspace.
5. **Knowledge base** — drag-and-drop / выбор файла, документ появляется в списке сессии.
6. **Telegram** — переключатель «Подключить / Отключить» без реального API.
7. **Settings** — компактные списки влияют на отступы в TaskList; тема зафиксирована светлой с пояснением.

## Локализация

По запросу весь пользовательский текст переведён на **русский**: навигация, дашборд («Добрый день, Алексей»), формы, уведомления, мок-активность, AI-шаблоны, `aria-label`, `index.html` (`lang="ru"`).

Бренды **Aivibe**, **AivibeBoard**, **Medialog**, **Northwind** в названиях проектов сохранены где уместно.
